## 3. 长描述 · English (Markdown, Modrinth-ready)

```markdown
# PMWeather Lite

**Extreme weather simulation for Forge 1.20.1 — the sky belongs to your shader pack, the physics stays here.**

Most weather mods want to own the renderer. This one doesn't. It simulates the atmosphere,
then asks vanilla Minecraft to rain — so Oculus, Iris and any shader pack that supports
rain and thunder will draw their own volumetric storm clouds and lightning on top.

No post-processing hijack, no shader conflicts, no "works only with pack X".

## What it does

- **18 extreme weather types** across 7 categories: supercell, tornado, squall line,
  downburst, hail, hurricane, extratropical cyclone, blizzard, ice storm, sleet, dust storm,
  Martian dust storm, heat wave, cold wave, fire whirl, wildfire, flash flood, rainstorm.
- **Thermodynamically driven spawning.** Each evaluation builds a vertical sounding and
  computes CAPE, CINH and low-level CAPE. Below a risk of 0.35 no storm forms — a stable
  atmosphere stays quiet. Higher risk means stronger, wider storms.
- **4 storm types** with their own growth, rain output and lightning rates, plus multi-vortex
  sub-vortices.
- **Tornado destruction.** Blocks above the local wind threshold get ripped out as swirling
  falling-block entities. Leaves 50–65, wool 60, glass 70, chests 120; dirt, gravel and
  bedrock are immune.
- **Wind-driven wildfire.** Fire jumps downwind, and fire whirls ignite new columns.
- **Alerts and sound.** Tornado touchdown siren, severe weather warnings on the action bar,
  per-player mute. Every sound is a vanilla `SoundEvent` — the jar ships zero audio files.

## Requirements

- Minecraft 1.20.1
- Forge 47.2.0+
- Java 17
- Optional: Oculus 1.8.0 + Embeddium 0.3.31 and any shader pack

Works on servers too — the simulation is server-side, clients only need the mod for
particles and alerts.

## Commands (OP level 2)

| Command | Effect |
|---|---|
| `/pmwlite list` | List all weather types by category |
| `/pmwlite weather <TYPE>` | Trigger a type at your position |
| `/pmwlite summon` | Summon a supercell |
| `/pmwlite status` | Active events, storm count, remaining time |
| `/pmwlite mute` | Toggle your own weather sounds |
| `/pmwlite clear` | Clear all weather |

## Performance

The v4 pass removed allocation from every hot path: array-backed soundings instead of a
boxed `TreeMap`, block-identity lookups instead of registry-name strings, and one batched
particle packet instead of one per particle.

| Path | Before | After |
|---|---|---|
| Sounding (17 layers + CAPE + phase) | 4.2 µs · 1840 B | 2.5 µs · 504 B |
| Destruction scan (315 blocks) | 104.9 ms / 1000 | 12.0 ms / 1000 |
| Precipitation packets | ~60 /s /player | ~10 /s /player |

## Compatibility

- Shader packs: any pack that renders rain/thunder. Tested with Complementary and Cristal.
- Weather mods: do **not** run alongside Weather2 — both drive vanilla rain state.
- Seasons/temperature mods: unaffected, this mod reads biome climate but never writes it.

## Credits

Algorithm concepts and parameter ranges are inspired by **ProtoManly's Weather (PMWeather)**
by ProtoManly, distributed under an All Rights Reserved license. This is an independent
reimplementation for Forge 1.20.1 — it contains none of the upstream source code, shaders,
textures or audio. The atmospheric physics used (Magnus saturation vapour pressure, Bolton
virtual temperature, CAPE integration, Rankine vortex) is public-domain meteorology.

Not affiliated with or endorsed by Mojang Studios or the PMWeather author.
```

## 4. 长描述 · 中文 (Markdown)

```markdown
# PMWeather Lite

**Forge 1.20.1 的极端天气模拟 —— 云交给光影包，物理留在这里。**

大多数天气 mod 都想接管渲染器，这个不想。它只负责模拟大气，然后让原版 Minecraft
下雨 —— 于是 Oculus、Iris 以及任何支持雨天/雷暴的光影包，都会自己画出体积风暴云和闪电。

不劫持后处理管线，不与光影冲突，不存在"只支持某个光影包"。

## 它能做什么

- **18 种极端天气**，分 7 类：超级单体、龙卷风、飑线、下击暴流、冰雹、飓风、温带气旋、
  暴风雪、冰暴、雨夹雪、沙尘暴、火星尘暴、热浪、寒潮、火龙卷、野火、山洪、特大暴雨。
- **热力学驱动生成**。每次评估都会构建垂直探空，计算 CAPE、CINH 与低层 CAPE。
  风险低于 0.35 不生成 —— 稳定大气就该安静。风险越高，风暴越强越宽。
- **4 种风暴类型**，各有不同的生长速率、降水量与闪电频率，含多涡旋子涡。
- **龙卷破坏**。超过局部风速阈值的方块会被卷成带切向速度的下落方块：
  树叶 50–65、羊毛 60、玻璃 70、箱子 120；泥土、砂砾、基岩免疫。
- **风驱野火**。火势顺风跳跃，火龙卷能点燃新火柱。
- **预警与音效**。龙卷触地警笛、action bar 极端天气预警、个人静音开关。
  全部复用原版 SoundEvent —— jar 里没有一个音频文件。

## 环境要求

- Minecraft 1.20.1
- Forge 47.2.0+
- Java 17
- 可选：Oculus 1.8.0 + Embeddium 0.3.31 + 任意光影包

服务端同样可用：模拟在服务端跑，客户端只需装 mod 以获得粒子和预警。

## 命令（OP 等级 2）

| 命令 | 作用 |
|---|---|
| `/pmwlite list` | 按类别列出全部天气 |
| `/pmwlite weather <TYPE>` | 在当前位置触发指定天气 |
| `/pmwlite summon` | 召唤超级单体 |
| `/pmwlite status` | 活动事件、风暴数量、剩余时间 |
| `/pmwlite mute` | 切换个人天气音效 |
| `/pmwlite clear` | 清除全部天气 |

## 兼容性

- 光影：任何渲染雨天/雷暴的光影包。已在 Complementary、Cristal 上验证。
- 天气 mod：**不要**与 Weather2 同时使用 —— 两者都会驱动原版雨态。
- 季节/温度 mod：无冲突，本 mod 只读取群系气候，从不写入。

## 致谢

算法思路与参数体系参考 **ProtoManly's Weather (PMWeather)**（作者 ProtoManly，ARR 授权）。
本项目是针对 Forge 1.20.1 的独立重写，不含上游任何源码、shader、贴图或音频。
所用大气物理公式（Magnus 饱和水汽压、Bolton 虚温、CAPE 积分、Rankine 涡旋）属公有领域。

与 Mojang Studios 及 PMWeather 作者无隶属或背书关系。
```

## 7. 审核要点

1. **授权链**：项目为 ARR，但**允许未修改的 jar 随整合包分发**（LICENSE 第 1.b 条），
   这一点要在项目描述里点明，否则整合包作者不敢用。
2. **第三方声明**：必须写明参考 PMWeather（ARR）且不含其资源 —— 两个平台的审核都会看。
3. **不要写"移植/Ported"**：容易被认为是上游的衍生作品。统一用
   "independent reimplementation / 独立重写"。
4. **无前置依赖**：不要填 Oculus 为 required dependency，它是 optional。
5. **文件名**：`PMWeatherLite-0.1.0.jar`，与 `mods.toml` 的 `version` 保持一致。
