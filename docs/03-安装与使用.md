# PMWeatherLite — 安装与使用（Forge 1.20.1 · 兼容光影）

这是按路线 A 独立重写的 PMWeather 等价 mod，**能和你开的光影包（Oculus/Iris）共存**。
源码与构建工程在 `E:\mc_pack_work\PMWeatherLite\`，设计文档见同目录两份 md。

## 一、它是什么

- 把 ProtoManly's Weather 的**天气物理内核**（热力学/风场/Rankine 涡旋/风暴演化）移植到 Forge 1.20.1；
- 扩展为 **18 种现实极端天气**（龙卷 EF0-5、飓风 1-5 级、冰雹、暴风雪、冰冻雨、沙尘暴、热浪、寒潮、野火、山洪…）；
- **云和闪电交给光影包画**（本包已有 Oculus 1.8.0 + Embeddium），mod 只出粒子/实体并驱动原版天气状态 → **光影全兼容，不用再关光影切来切去**。

## 二、安装

1. 把 `PMWeatherLite-0.1.0.jar` 放进整合包的 `mods/` 文件夹。
2. ⚠️ **必须和 Weather2 二选一**：两者都接管天气，同时开会互相覆盖。
   - 想要"光追体积风暴云 + 18 种天气" → 删掉 `weather2-*.jar` 和 `coroutil-*.jar`，留本 mod + 体积云光影包。
   - 想保留 Weather2 → 就别装本 mod。
3. 建议装一个体积云光影包（Complementary Reimagined / Cristal Shaders / Aureveil），
   放进 `shaderpacks/` 并在游戏内启用。不开光影也能跑，只是云用原版粒子表现。
4. Forge 版本 47.2.0（本包已是），内存 6–8GB。

## 三、命令（需 OP 权限 2）

| 命令 | 作用 |
|---|---|
| `/pmwlite list` | 列出全部 18 种天气类型 |
| `/pmwlite weather <TYPE>` | 触发指定天气，如 `/pmwlite weather TORNADO`、`/pmwlite weather DUST_STORM` |
| `/pmwlite summon` | 在脚下生成超级单体风暴（快速看龙卷） |
| `/pmwlite clear` | 清除所有活动天气 |

可用 TYPE（枚举名）：SUPERCELL, TORNADO, SQUALL_LINE, DOWNBURST, HAIL, HURRICANE,
TYPHOON_EXTRATROPICAL, BLIZZARD, ICE_STORM, SLEET, DUST_STORM, SANDSTORM_MARS,
HEAT_WAVE, COLD_WAVE, FIRE_WHIRL, WILDFIRE, FLASH_FLOOD, RAINSTORM

## 四、能看到什么

- **风暴来临时**：光影包的天空转成暴雨天色，频繁闪电（分叉闪电实体，光影会打出闪光）；
- **龙卷**：漏斗状烟尘粒子柱，切向旋转，卷起的方块绕漏斗飞（EF 越高破坏半径越大）；
- **降水**：按热力学温度廓线自动判定雨/雪/雨夹雪/冻雨/冰雹——寒冷生物群系下雪，强对流里夹冰雹；
- **火龙卷/野火**：火焰柱 + 风驱蔓延，下风向可燃物被依次点燃；
- **沙尘暴**：黄褐色天幕（雾效）+ 沙尘粒子，能见度按等级衰减；
- 服务端每 30 秒按真实形成条件评估一次天气（暖湿才生对流、海洋才生飓风、干旱才生沙尘、低温才生冬季降水）。

## 五、已知边界（诚实说明）

- 云的最终观感由**光影包**决定；本 mod 不画体积云（这是兼容光影的代价）。
- 数值做了游戏化简化（现实龙卷直径 100m 级，游戏内为可玩性放大）；分级体系对齐现实但半径为游戏尺度。
- 音效（龙卷警报/雷声定位）、雷达/风速计方块 GUI 暂未移植。
- 从零到编译成功历经 3 轮 API 修正（1.20.1 与 1.21.1 的 FallingBlockEntity/StringArgumentType/Biome API 差异），已通过 `./gradlew build`。
