# 环境光学现象模拟 / Environmental Optics

> 版本：v0.3.3 · 依赖：多气体列场 `GasField` + 本地大气场 `AtmosphereGrid` + 光学求解器 `OpticalField`

本文档明确本功能的**数据字段、参数范围、触发条件、状态变化、输出表现**，并把
**科学可解释现象**与**艺术化夸张**逐条分开——不把演绎冒充成物理。

---

## 1. 设计边界：什么是真的，什么是演绎

Minecraft 是一个**地表**方块游戏。真实大气光学里有一大类发生在我们根本没模拟的圈层：

| 现象 | 真实物理 | 本 mod 的处理 |
|---|---|---|
| 幻日 / 日晕 | 5–10 km 卷层云六角冰晶折射，22°，内红外紫 | ✅ 科学可解释：用露点<0℃ 代理冰晶、云量代理卷层云、太阳高度角代理观测几何 |
| 雾虹 | 近饱和雾滴背光散射 | ✅ 科学可解释：湿度/露点差/低云底/低太阳角 |
| 污染霞光 | 气溶胶米氏散射滤短波 | ✅ 科学可解释（比例游戏化）：PM/SO₂/NO₂ + 低太阳角 |
| 极光 | 100–300 km 电离层，太阳风带电粒子沿地磁场沉降，激发氧(557.7/630nm)与氮(427.8nm) | ⚠️ **艺术化**：MC 无电离层、无太阳风沉降，不存在产生真实极光的物理过程。用"高磁纬+夜+地磁扰动代理+通透天空"演绎，HUD 明确标注 `[艺术化]` |

原则：**现象的物理方向是对的**（低太阳角才有幻日、夜里高纬才有极光），但**代理量是游戏化的**
（纬度用 |z|、地磁活动用雷暴强度）。界面上科学现象标 `[科学]`、极光标 `[艺术化]`。

## 2. 数据字段与参数范围

### 2.1 多气体列场 `GasField`（新增）

在 CO₂ 三维体场之外，新增 4 种机器废气的**二维列场**（地表边界层，16×16 列）。
用二维而非三维的理由：排放源在地表、光学只看整列积分浓度、二维平流每步只 1024 次采样（性能）。

| 下标 | 键 | 名称 | 背景值 | 上限 | 主要来源 |
|---|---|---|---|---|---|
| 0 | `so2` | 二氧化硫 | 5e-7（0.5 ppb） | 2e-3 | 岩浆/岩浆块/灵魂火、熔炉/高炉含硫矿 |
| 1 | `no2` | 二氧化氮 | 2e-8（0.02 ppb） | 1e-3 | 爆炸(TNT)、燃烧机器高温固氮 |
| 2 | `co` | 一氧化碳 | 1e-4（0.1 ppm） | 1e-2 | 火/营火不完全燃烧、燃烧机器 |
| 3 | `pm` | 颗粒物 | 0 | 1（浑浊度指数） | 熔炉/烟熏炉烟尘、火 |

- 字段：`c[gas][col]`（浓度）、`cN`（平流双缓冲）、`src[gas][col]`（源强度 0..1）。
- 平流：与 CO₂ 同源的半拉格朗日回溯，退化为水平 (u,v) 两分量；边界按最近格（开放边界）。
- 通风：边界层每步向背景松弛（时间常数 240 s），源移除后几分钟回落。
- 兼容层入口：`AtmosphereGrid.injectGas(x, z, key, strength)` / `GasField.inject(...)`，
  供 KubeJS / 其他 mod 精确注入任意气体，无需硬编码方块表。
- 自动源：滚动扫描（每步 32 列、8 步一轮），按 `BlockStateProperties.LIT` 通用属性接入
  Create / GTCEu 等耗氧机器。

### 2.2 光学输入 `OpticalField.Input`

| 字段 | 来源 | 范围 | 说明 |
|---|---|---|---|
| `tempC` | 大气探针 | −90…70 ℃ | 气温 |
| `humidity` | 探针 | 0…1 | 相对湿度 |
| `dewPointC` | 探针（Magnus 公式） | ℃ | 露点，判定冰晶/雾滴的关键 |
| `cloud` | 探针（整列最大云量） | 0…1 | 卷层云/雾的厚度代理 |
| `cloudBaseM` | 探针（LCL=125·(T−Td)） | m | 云底高度，雾虹要低云底 |
| `sunAltitudeDeg` | 游戏时间解算 | −90…90 ° | 太阳高度角，负=地平线下 |
| `geomagneticLat` | \|z\|/24 | 0…90 ° | ⚠️ 艺术化代理：地磁纬度 |
| `kp` | 雷暴等级+强风暴数 | 0…9 | ⚠️ 艺术化代理：地磁活动指数 |
| `so2/no2/co/pm/co2` | 多气体场+CO₂场 | 见 2.1 | 影响霞光、通透度 |
| `underground` | 探针 | bool | 地下不触发任何天空现象 |

### 2.3 光学输出 `OpticalField.Result`

- `strength[6]`：NONE / 幻日 / 日晕 / 雾虹 / 霞光 / 极光，各 0..1。
- `dominant`：主导现象（最强且 ≥0.18 者，否则 NONE）。
- `artistic`：`!dominant.scientific`，即主导是不是艺术化现象。
- `durationSec` / `phase`：状态机维护的持续时间与"形成中/稳定/消退中/静默"。

## 3. 触发条件（强度为连续函数，非硬阈值）

所有现象强度都是钟形/界限函数的乘积，阈值处平滑，避免云飘过时硬闪。

### 3.1 幻日 PARHELION `[科学]`
- 太阳高度角：峰值 18°、宽 24°；**>60° 迅速消失**（阳光无法水平穿过竖直冰晶侧面）。
- 云量：峰值 0.45（薄卷层云，太厚遮太阳）。
- 冰晶：露点 < −2℃ 且气温 < 14℃（卷层云由冰晶而非水滴组成）。
- 通透：PM < 0.45（气溶胶太多无法形成清晰光斑）。
- 现实依据：六角片晶水平取向，60° 顶角棱镜两次折射，最小偏向 21.84°；近太阳红、外侧蓝紫（色散）。

### 3.2 日晕 HALO `[科学]`
- 太阳高度角 −8…80°（比幻日宽松）；云量峰值 0.72（更厚）；露点 < −3℃；PM < 0.55。
- 现实依据：冰晶取向随机 → 22° 收不成点而摊成整圈；内红外紫。

### 3.3 雾虹 FOGBOW `[科学]`
- 湿度 > 0.88；\|气温−露点\| < 3℃（近饱和）；云底 < 260 m（低雾）；太阳 0…40°。

### 3.4 污染霞光 AFTERGLOW `[科学，比例游戏化]`
- PM > 0.18 且 SO₂+NO₂ 足够；太阳高度角约 0°（日出日落）时最强。
- 现实依据：低角度阳光穿气溶胶，米氏散射滤掉短波、留红褐。把浓度映射到霞光强度是游戏化比例。

### 3.5 极光样光幕 AURORA `[艺术化]`
- 夜间（太阳 < −6°）＋ 高磁纬（>40°，用 \|z\| 映射）＋ Kp>4（雷暴代理）＋ 通透（云<0.55、PM 低）。
- 配色遵循现实：绿(557.7nm 氧) 为主，强时顶部红(630nm 氧)、底缘蓝紫(427.8nm 氮)。
- **再次强调**：这是演绎，MC 地表无电离层/太阳风，HUD 标 `[艺术化]`。

## 4. 状态变化（状态机 `OpticalTracker`）

- **1 Hz** 更新一次（与大气探针同频），不做每 tick 求解。
- 指数平滑：**淡入 τ=1.5 s（快）、淡出 τ=4 s（慢）**，避免阈值抖动导致闪烁。
- 主导现象滞后：上一主导若仍 ≥0.18 且 ≥新最强的 75%，保留，防止两个强度接近时来回跳。
- 三阶段：目标比当前高 >0.04 → "形成中"；低 >0.04 → "消退中"；否则"稳定"；无可见现象 → "静默"。
- 持续时间：连续可见（≥0.18）的秒数，退出可见即清零。

## 5. 输出表现

| 通道 | 内容 | 光影兼容 |
|---|---|---|
| 屏幕叠加层 `OpticsOverlayLayer` | 极光帘幕（≤10 带，绿/红/蓝紫分层，正弦流动）、幻日双光斑（内红外紫）、22° 日晕环、雾虹弧、霞光渐变 | 全 2D `GuiGraphics`，光影包下照常生效，不碰光影后链 |
| 右上角 HUD | 现象名 + `[科学]`/`[艺术化]` + 持续秒数 + SO₂/NO₂/CO(ppm)、PM(浑浊度%) | 同上 |
| 雷达 GUI `drawAtmos` | 同上现象行，与 HUD 同源 | — |
| 雾色/能见度 `AtmosphereLayer` | PM 计入污染浑浊度，雾色转黄褐、能见度下降 | 保留 `fogEventsAllowed()` 守卫，光影包下让位 |

极光的"照亮地面"用 2D 光幕近似，**不改 `LightingState`**，避免与光影包的光照联动冲突。

## 6. 配置开关（ServerConfig）

- `gasField`（默认 true）：多气体列场总开关；关闭后只有 CO₂，行为同 0.3.2。
- `opticsSystem`（默认 true）：光学求解与显示总开关。
- `opticsOverlay`（默认 true）：是否画屏幕叠加层；关掉只留 HUD 文字。

## 7. 验证

`/pmwlite atmoscheck` 自检 45 项（原 33 + 新增 12），本功能相关断言：
- SO₂/PM 初值为背景量级、注入成羽流、全场峰值上升且有界、随平流到下风；
- 幻日随太阳角降低而增强（15°≈0.40 vs 85°≈0.00）、标记科学；
- 极光需夜+高纬+磁扰（夜≈0.47 vs 昼≈0.00）、标记艺术化且为主导；
- 污染霞光在低角度+气溶胶下触发；所有强度 0..1 有限；地下无光学现象。

实测：专用服务器 45/45 PASS，本地场稳态单步约 996 µs（预算 <1500）。

## 8. 性能预算

- 多气体列场：4 气体 × 256 列 × 2 缓冲 = 8 KB；每步 1024 次二维三线性采样。
- 光学求解：1 Hz，5 个现象各若干次 exp，可忽略。
- 渲染：极光 ≤10 带、幻日 2 光斑×4 层、日晕 96 段、雾虹 40 段、霞光 6 带，全部固定上限、无分配。
