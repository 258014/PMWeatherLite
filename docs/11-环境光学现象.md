# 环境光学、多气体风险与天文现象 / Optics, Exposure & Astronomy

> 版本：v0.3.4 · 依赖：`GasField`（多气体列场）+ `AtmosphereGrid`（本地大气场）
> + `GasExposure`（联合暴露）+ `OpticalField` / `OpticalTracker`（光学求解与状态机）
> + `LunarField`（月相与月食纯函数）

本文档明确**数据字段、参数范围、触发条件、状态变化、输出表现**，并把
**科学可解释现象**与**艺术化夸张**逐条分开——不把演绎冒充成物理。

---

## 1. 设计边界：什么是真的，什么是演绎

Minecraft 是**地表**方块游戏。真实大气光学中有一大类发生在我们没模拟的圈层：

| 现象 | 真实物理 | 本 mod 处理 |
|---|---|---|
| 幻日 / 22° 日晕 / 环天顶弧 / 环地平弧 / 日柱 | 5–10 km 卷层云六角冰晶的折射与反射；板晶取向决定弧的形状；22°，内红外紫 | ✅ 科学可解释：露点<0℃ 代理冰晶、云量代理卷层云、太阳高度角代理观测几何 |
| 虹彩云 / 月华 | 小水滴或冰针的衍射，柔和彩环，内蓝绿外红棕 | ✅ 科学可解释：薄云 + 水滴/冰晶 + 光源高度 |
| 雾虹 / 宝光 | 雾滴背光散射；宝光是观察者在云雾上影子的彩色光环，红色外缘 | ✅ 科学可解释：近饱和 + 低云底 + 背向光源 |
| 双彩虹（主虹+霓） | 水滴一次/两次内反射，主虹内紫外红、霓内红外紫且暗，中间亚历山大暗带 | ✅ 科学可解释：低太阳角 + 降水 + 背向观测 |
| 曙暮辉 / 反曙暮辉 | 云或地形遮挡阳光形成光束，透视上分别汇聚到太阳与反日点 | ✅ 科学可解释：晨昏 + 部分云量 |
| 维纳斯带 / 地球阴影 | 民用暮光时反日侧地平线上方粉红带与其下方地球本影；月食同源 | ✅ 科学可解释：太阳 −1…−12°，低气溶胶 |
| 气辉 | 80–100 km 高层大气化学发光（真实但极暗） | ✅ 科学可解释，按比例提亮（×0.45，比极光暗一档） |
| 法塔莫甘娜 | 强近地逆温形成大气波导，地平线出现垂直堆叠的畸变蜃景 | ✅ 科学可解释：逆温 + 低太阳角 + 通透 |
| 蓝太阳 / 绿闪 | 浓气溶胶滤掉长波；日出日落折射+近地蜃景留下绿色像 | ✅ 科学可解释：气溶胶与地平线几何 |
| 月相 / 月面明暗 / 月光照明 / 月食 | 8 相周期、 terminator 几何、满月近交点时地球本影遮月（铜红边） | ✅ 科学可解释；食季周期压缩到 48 MC 日（游戏化） |
| 污染霞光 | 气溶胶米氏散射滤短波 | ✅ 科学可解释，浓度→强度比例游戏化 |
| 极光样光幕 | 100–300 km 电离层，太阳风沉降激发氧(557.7/630nm)与氮(427.8nm) | ⚠️ **艺术化**：MC 无电离层、无太阳风沉降。用高磁纬+夜+地磁扰动代理演绎，HUD 标 `[艺术化]` |

原则：**物理方向对**（低太阳角才有环天顶弧、>58° 才有环地平弧、夜里高纬才有极光），
**代理量游戏化**（纬度用 |z|、地磁活动用雷暴强度、食季压缩）。

## 2. 数据字段与参数范围

### 2.1 多气体列场 `GasField`（v0.3.3）与湿沉降（v0.3.4）

CO₂ 在 `AtmosphereGrid` 的三维体场里；SO₂/NO₂/CO/PM 用 16×16 二维列场（地表边界层）。
二维的理由：排放源在地表、光学只看整列积分浓度、每步只 1024 次采样。

| 下标 | 键 | 名称 | 背景值 | 上限 | 主要来源 |
|---|---|---|---|---|---|
| 0 | `so2` | 二氧化硫 | 5e-7（0.5 ppb） | 2e-3 | 岩浆/灵魂火、含硫矿冶炼 |
| 1 | `no2` | 二氧化氮 | 2e-8（0.02 ppb） | 1e-3 | 爆炸高温固氮、燃烧机器 |
| 2 | `co` | 一氧化碳 | 1e-4 | 1e-2 | 火/营火不完全燃烧、燃烧机器 |
| 3 | `pm` | 颗粒物 | 0 | 1（浑浊度） | 熔炉/烟熏炉烟尘、火 |

- 平流：半拉格朗日回溯，与 CO₂ 共享风场，羽流沿同一条风路。
- 通风：向背景松弛，时间常数 240 s。
- **湿沉降 v0.3.4**：`step(gameTime, rain)` 增加洗出项
  `c ← bg + (c−bg)·exp(−k·rain·dt)`；SO₂ τ=150s、NO₂ τ=260s、PM τ=120s、
  CO τ=2400s（难溶，几乎不洗出）。由 `wetDeposition` 开关控制。
- 兼容层入口：`AtmosphereGrid.injectGas(x, z, key, strength)` /
  `GasField.inject(x, z, gas|key, strength)`，供 KubeJS 或其他 mod 精确注入。
- 自动源：按 `BlockStateProperties.LIT` 通用属性接入 Create / GTCEu 等机器。

### 2.2 联合暴露 `GasExposure.Input → Result`（v0.3.4 新增）

输入：SO₂ / NO₂ / CO / PM / CO₂ 浓度 + 降水强度（0..1）；输出：

| 字段 | 范围 | 含义 |
|---|---|---|
| `index` | 0..1 | 归一化综合暴露，含协同与湿沉降修正 |
| `grade` | NONE/MILD/MODERATE/SEVERE/CRITICAL | 5 级风险，对应 0.12/0.35/0.62/0.85 边界 |
| `visibility` | 0.06..1 | 能见度折扣；PM 主因，SO₂ 与 CO₂ 次之 |
| `parts[5]` | 0..3 | 各气体归一化份额，用于找主导 |
| `dominant` | 0..4 | 贡献最大的气体（SO₂/NO₂/CO/PM/CO₂） |

协同项：`0.45·min(SO₂,PM) + 0.35·min(NO₂,CO) + 0.25·min(SO₂,NO₂)`。
这保证"每种都低于单气体阈值"时组合仍可能升级——自检里验证组合指数 > 单气体 1.4 倍。

**影响范围**：本地 16×16 格 × 16 m = **256×256 方块**窗口，随玩家重心滚动；
探针取玩家眼高，判定与 HUD 使用同一份探针和同一份降雨读数。离开羽流 4 秒内效果自然消退。

**变化表现**（由 `AtmosphereManager.applyExposure()` 施加原版效果）：

| 等级 | 人物表现 | 环境表现 |
|---|---|---|
| MILD | 挖掘疲劳 | 轻度黄灰雾色 |
| MODERATE | 疲劳 + 虚弱；CO/CO₂ 主导时反胃 | PM 浑浊可见、能见度下降 |
| SEVERE | 虚弱 + 反胃 + 短时失明；CO/CO₂/PM 主导时中毒 | 霞光偏红褐、蓝太阳可能出现 |
| CRITICAL | 中毒 + 凋零 + 2s 冷却的缓慢伤害 | 浓浑浊 + 低能见度 |

### 2.3 光学输入 `OpticalField.Input`

原有字段：`tempC, humidity, dewPointC, cloud, cloudBaseM, sunAltitudeDeg, geomagneticLat, kp,
so2/no2/co/pm/co2, underground`。

v0.3.4 追加（缺省 0 对旧调用兼容）：

| 字段 | 来源 | 范围 | 用途 |
|---|---|---|---|
| `inversionC` | (T−Td)·0.55·(1−cloud) | 0..12 ℃ | 法塔莫甘娜的近地逆温代理 |
| `moonAltitudeDeg` | `LunarField.altitudeDeg()` | −90..90 ° | 月华、月食的可见性 |
| `moonIllum` | `LunarField.illumination()` | 0..1 | 月华亮度 |
| `moonEclipse` | `LunarField.eclipse()` | 0..1 | 月食强度，同时压低月华 |
| `rain` | `level.getRainLevel()` | 0..1 | 双彩虹/宝光的水滴条件 |

### 2.4 光学输出 `OpticalField.Result` 与 wire contract

- `strength[22]`：NONE + 21 种现象，各 0..1。
- `dominant`：最强且 ≥0.18 者，否则 NONE；`artistic = !dominant.scientific`。
- `durationSec / phase`：1 Hz 状态机，淡入 τ=1.5 s、淡出 τ=4 s，主导滞后 0.75 倍避免跳变。
- **Kind ordinal 是网络协议**：前 6 个（NONE/PARHELION/HALO/FOGBOW/AFTERGLOW/AURORA）
  与 v0.3.3 完全一致，16 个新现象**只能追加在末尾**。`KIND_COUNT = 22`。

## 3. 22 种现象的触发条件（连续强度，非硬阈值）

### 3.1 原有 5 种 + 艺术化 1 种

- **幻日** `[科学]`：太阳 18°±24°、云量 0.45±0.26、露点<−2℃、PM<0.45；>60° 消失。
- **日晕** `[科学]`：太阳 −8…80°、云量 0.72±0.30、露点<−3℃、PM<0.55。
- **雾虹** `[科学]`：湿度>0.88、|T−Td|<3℃、云底<260 m、太阳<40°。
- **污染霞光** `[科学]`：PM>0.18 且有 SO₂/NO₂、|太阳角|≈3°±16°。
- **极光样光幕** `[艺术化]`：夜（太阳<−6°）、|z|/24≥40°、Kp≥4、云<0.55、PM<0.35。

### 3.2 冰晶弧族（新增）

| 现象 | 观测几何 | 云/粒子条件 | 画面色序 |
|---|---|---|---|
| 环天顶弧 `[科学]` | 太阳 **≤32°**，峰值 15° 附近；>32° 归零 | 云 0.42±0.20，冰晶，PM<0.45 | **蓝紫在上、红在下**（顶面入侧面出） |
| 环地平弧 `[科学]` | 太阳 **>58°**，峰值 ~70° | 同上薄卷层云与冰晶 | **红在上、紫在下**（侧面入底面出），高纬难见 |
| 日柱 `[科学]` | 太阳 ≈0°±13°，允许略低于地平线 | 冰晶 + 云<0.70 + 通透 | 竖直暖白光柱 |

### 3.3 水滴/衍射/散射族（新增）

| 现象 | 触发条件 | 画面表现 |
|---|---|---|
| 虹彩云 `[科学]` | 云 0.45±0.22、太阳 35°±30°、露点>−20℃、通透 | 太阳周围 4 片粉彩柔斑，缓慢漂移 |

| 双彩虹 `[科学]` | 太阳<42°、雨或近饱和水滴、云 0.65±0.30 | 主虹内紫外红；外侧霓内红外紫且暗一档，中间留暗带 |
| 月华 `[科学]` | 月亮>3°、照度>0、薄云 0.42±0.22、通透；月食时衰减 | 月亮周围内蓝绿外红棕彩环 |

### 3.4 曙暮与地影族（新增）

| 现象 | 太阳高度角窗口 | 表现 |
|---|---|---|
| 曙暮辉 `[科学]` | ≈+2°±10°，云 0.50±0.30 | 12 束光从太阳发散 |
| 反曙暮辉 `[科学]` | ≈−2°±9°，云 0.45±0.30 | 同一束光在反日侧汇聚 |

| 地球阴影 `[科学]` | ≈−3.5°±3°，气溶胶少、云<0.70 | 粉红带下方暗蓝楔形（地球本影） |
| 气辉 `[科学]` | 太阳<−12°，云<0.50、PM<0.30 | 高空淡绿横带，强度 ×0.45（比极光暗） |

### 3.5 地平线畸变与极限色（新增）

| 现象 | 触发条件 | 表现 |
|---|---|---|
| 法塔莫甘娜 `[科学]` | `inversionC`>4℃（满值 12）、\|太阳角\|<20°、云<0.60 | 地平线 5 层上下错位、随时间起伏的蜃景带 |
| 蓝太阳 `[科学]` | PM>0.35 或 SO₂+NO₂>6e-4、\|太阳角\|≈12°±25° | 太阳位置蓝灰光斑 |
| 绿闪 `[科学]` | \|太阳角\|<2.5°、PM<0.15、云<0.50、空气干洁 | 地平线短暂绿色小弧 |

### 3.6 月亮（新增）

`LunarField` 纯函数与 MC 原生 8 相周期对齐：0=满月、4=新月；
照度 = (1+cos(2π·phase/8))/2；月高 = −太阳高；月光 = 照度 × 可见性 × 云透过率 × (1−0.92·食)。

- **月相变化 / 月面明暗**：逐行画月牙，明暗界线宽度 `(1−2·illum)·√(r²−y²)`；
  illum=0 全暗、0.5 半月、1 满月；盈月亮边在右、亏月在左。
- **月光照明**：夜间向 `LightingState.ambient` 补最多 0.18 的冷色环境光，
  白天由 `(1−daylight·0.85)` 压到≈0，**不改白昼标定，不写光影包 uniform**。
- **月食 `[科学]`**：满月（照度>0.96）+ 食季（每 6 周期=48 MC 日）+ 月亮在地平线上；
  强度按距交点天数线性衰减到 0，画面为暗铜盘 + 折射红铜外缘，同时压低月华。

## 4. 状态变化与网络

- `AtmosphereManager.updateOptics()` 1 Hz 用玩家重心探针更新 `OpticalTracker`；
  新增"雨、逆温、月相/照度/食"输入。
- `AtmosOpticsPacket` **协议升 `"5"`**：`float[] strengths`（长度随 `KIND_COUNT` 自动扩展）
  + 月相/照度/高度/食/月光 5 个字段。客户端 `ClientVisualState` 整体替换数组引用，
  避免 22 个 float 被渲染线程读到半更新状态。
- `AtmosProbePacket` 同包下发 `exposure / exposureGrade / visibility`，
  让 HUD 显示的风险等级就是服务端扣血用的等级。
- `moonSystem=false` 时服务端下发全 0 月亮读数并清零月华/月食强度，画面与读数一起熄灭。

## 7. 验证

`/pmwlite atmoscheck` 自检从 45 项扩展到 **77 项**，本功能相关断言：

- 联合暴露：清洁空气无风险；SO₂+PM 协同指数 > 单气体 1.4 倍；降雨降低暴露并提高能见度；
  CO 不被雨水洗出；极端输入指数/能见度仍 0..1 有界。
- 月亮：0=满月照度≈100%、4=新月≈0；满月+食季触发月食、新月与非食季不触发；
  正午月亮在地平线下；云量削弱月光。
- 光学：前 6 个 ordinal 与 v0.3.3 wire contract 一致、`KIND_COUNT=22`；
  环天顶弧只在≤32°触发、环地平弧在70°触发；日柱随太阳升高消失；
  虹彩云/宝光/双彩虹/月华/曙暮辉/反曙暮辉/维纳斯带/地球阴影/气辉/
  法塔莫甘娜/蓝太阳/绿闪各自在构造条件下超过阈值；月食压低月华；
  极端输入下 22 种强度仍有限且有界；除极光外全部标记科学。

## 8. 性能预算

- 多气体列场：4×256×2 缓冲 = 8 KB；湿沉降每步 1024 次乘加，可忽略。
- 联合暴露：1 Hz 每玩家一次，20 次浮点运算 + 一次 exp（湿沉降在列场侧）。
- 光学求解：1 Hz，钟形函数约 20 次 exp；22 种现象合计仍远低于 1 ms。
- 渲染：极光≤10 带、每弧≤48 段、光束 12×8 段、月亮逐行 ≤2r≈30 行；
  全部固定上限、无纹理分配，光影包下同样生效。
