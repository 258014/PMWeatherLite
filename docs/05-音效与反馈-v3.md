# PMWeatherLite v3 更新说明：音效 / 交互反馈 / 边界处理

> 日期：2026-11-18。基线：v2（26 class / 63KB）→ v3（**28 class / 71KB**）。
> 原则：**保持核心功能与代码风格不变，最小必要改动**。本轮只加"感知层"，未改天气物理与渲染架构。

---

## 一、新增：声音系统（`sound/SoundManager.java`）

### 1.1 关键操作音效

| 操作 | 音效（原版事件） | 说明 |
|---|---|---|
| `/pmwlite summon` 生成风暴 | `LIGHTNING_BOLT_THUNDER` | 雷声，符合"召唤风暴"的语义 |
| `/pmwlite weather <类型>` 成功 | `NOTE_BLOCK_PLING`(升调 1.4) | 清脆确认音 |
| `/pmwlite weather <错误类型>` | `NOTE_BLOCK_BASS`(降调 0.8) | 低沉否定音，与成功音区分 |
| `/pmwlite clear` 清除 | `BELL_BLOCK` | 钟声，表示"平息" |
| `/pmwlite mute` 切换 | 开→`PLING` / 关→`BASS` | 即时反馈当前静音状态 |

### 1.2 提示音（自动触发，带冷却）

| 场景 | 音效 | 冷却 | 附带文字反馈 |
|---|---|---|---|
| 龙卷风**首次触地**（边沿触发） | `BELL_RESONATE` 长钟 | 400 tick | 屏幕 ActionBar：`⚠ 龙卷风触地！EF3 — 立即寻找掩体` |
| 极端天气逼近（18 类型系统） | `RAID_HORN` 号角 | 600 tick | ActionBar：`⚠ 极端天气来袭：沙尘暴` |

> 设计要点：**边沿触发**（`touchedDown` 集合记录已报警的风暴 id），只在"首次触地"响一次，
> 不会每 tick 刷屏；冷却按玩家独立计算，多人服不会互相抢占。

### 1.3 静音开关（两级）

- **个人级**：`/pmwlite mute` 切换，状态按 UUID 记录（会话内有效）。
- **全局级**：`ServerConfig.soundEnabled`（默认 true），服主可一键关掉所有 mod 音效。
- 静音只影响**声音**，不影响 ActionBar 文字提示（文字默认仍然显示）。

### 1.4 为什么用原版音效

不引入任何 `.ogg` 资源文件：
- 零资源包依赖、不会被光影包/材质包影响；
- jar 体积几乎不变（+8KB 全是逻辑代码）；
- 避免"音频版权/资源缺失导致加载失败"的风险。

## 二、新增：交互反馈

1. **命令结果分色**：成功 `§a` 绿色、失败 `§c` 红色、类型名 `§e` 黄色、提示 `§7` 灰色。
2. **`/pmwlite weather` 类型补全**：输入时按 Tab 自动补全 18 种天气枚举名（之前要自己背）。
3. **错误提示更友好**：未知类型时提示"用 /pmwlite list 查看全部"，而不是只报错。
4. **`/pmwlite list` 按类别分组**：强对流/热带/冬季/沙尘/温度/火天气/水文 七组，一屏看懂。
5. **`/pmwlite status` 增强**：显示活动事件数、活跃风暴数、音效开关状态，以及每个事件的
   强度百分比和剩余秒数。

## 三、新增：边界情况处理

| # | 边界 | 处理 |
|---|---|---|
| B1 | 控制台/命令方块执行 `mute` | 检测 `getPlayer()` 为 null，友好提示"该命令只能由玩家执行"，返回 0 |
| B2 | 玩家退出后静音/冷却表残留 | `PlayerLoggedOutEvent` 清理该 UUID 的 MUTED 与 ALERT_COOLDOWN |
| B3 | 龙卷已消散但 id 还在报警集合 | `touchedDown` 超过 64 条时清理已不存在的风暴 id（防无界增长） |
| B4 | 风暴在无人区，粒子空转 | `TornadoFX` 增加"128 格内有玩家才出粒子"守卫（省网络与 CPU） |
| B5 | 无玩家在线 | `TornadoFX`/`WeatherStateBridge` 提前 return，不做无意义计算 |
| B6 | 音效播放对象为空 | `playUi` 对 null 玩家直接返回 |
| B7 | 提示音刷屏 | 按玩家 600/400 tick 冷却 + 边沿触发双保险 |
